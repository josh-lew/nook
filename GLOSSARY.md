# Glossary

## Idea

A low-effort capture of something the maker might want to make one day. Only a title and a hobby are required; it may also hold inspiration photos, a description, Pattern Options and Material Options. Ideas are deliberately loose and quick to create, and are ranked by the maker. An Idea she loses interest in sinks down the ranking or is deleted.

_Avoid_: draft, wishlist item, "planning project".

## Project

Something the maker has committed to making. A Project is created by Promoting an Idea (or directly) and moves through the Stages Planning → In progress → Completed. A Project is a living record that keeps being added to throughout its life; the app never forces details before a Stage change.

## Stage

Where a Project is in its life: **Planning** (committed, gathering the Pattern and materials), **In progress** (being made), or **Completed** (finished). An Idea has no Stage. A Project moves forward through the Stages; the only way back is from Completed to In progress. A Project never returns to Planning or to being an Idea.

_Avoid_: status (in conversation), phase.

## Paused

An In progress Project the maker has put down for now. Paused is not a Stage: a Paused Project is still In progress, shown as Paused there, and can be resumed.

_Avoid_: hibernating, abandoned, on hold.

## Promote

To turn an Idea into a Project, entering the Planning Stage. Nothing new is asked for: the Idea's hobby carries over. The Idea ceases to exist as an Idea; its content becomes the Project's Seed.

_Avoid_: convert, start (starting means moving a Project to In progress).

## Seed

The content a Project inherited from the Idea it was Promoted from, kept together so the maker can look back at where the Project began.

## Pattern

The instructions a Project is made from. A Project has at most one Pattern, made up of a link and/or one or more Pattern Files. A link alone is a complete Pattern.

## Pattern File

A file belonging to a Pattern, such as the purchased PDF, a chart, or a size guide.

## Pattern Option

A candidate pattern (link and/or screenshot, with an optional comment) saved on an Idea or a Project in Planning. Choosing one makes it the Pattern.

_Avoid_: pattern link (ambiguous with the Pattern's own link).

## Material Option

A candidate material, such as a yarn or fabric (link and/or screenshot, with an optional comment). Materials the maker settles on are marked as chosen.

## Gallery

The showcase of Completed Projects: every Completed Project appears in it.
