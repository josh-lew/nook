# 03: Idea screen: view, edit and delete

**What to build:** Tapping an Idea opens its screen, where the maker can edit the title, hobby and description, add or remove inspiration photos, and delete the Idea. Deleting is soft and removes it from the Ideas tab.

- [ ] Photos can be added and removed
- [ ] Delete soft-deletes the Idea and returns to the Ideas tab
